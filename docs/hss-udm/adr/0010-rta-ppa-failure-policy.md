# ADR-0010：RTA、PPA 失敗時有限重試；刪除開戶資料不因 RTA 失敗而停止

- 狀態：提案
- 日期：2026-10-22

## 背景

- TS 29.228 §6.1.3 沒有規定 RTA 失敗或沒有回應時 HSS 該怎麼做（用 grep 查過 §6.1.3 與 §8）。
- §6.2.2.1 規定了 PPA 的 5008、5009（改送 RTR SERVER_CHANGE）與 5001（換 IMPI 重送；沒有就設為 not registered）。
- cdp 的 `TransactionTimeout` 是 5 秒。

## 決定

- RTR、PPR 逾時或錯誤時，依 `cx.w8b.retry` 有限重試。
- RTR 重試用完：觸發來源是刪除開戶資料時，照樣刪除並告警（資料已經不該存在）；是管理操作時，狀態不變，回錯誤給呼叫者並告警。
- PPA 依 §6.2.2.1；其他錯誤重試用完只告警。

## 後果

- 好處：刪除開戶資料不會因為 S-CSCF 沒回應而卡住。
- 代價：刪除後 S-CSCF 可能仍保留該用戶的註冊，直到過期；告警需要人工確認。
- 對應需求：REQ-RTR-06、REQ-RTR-07、REQ-PPR-04；測試：T38、T40
